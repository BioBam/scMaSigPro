# Code of conduct

scMaSigPro follows the
[Bioconductor Code of Conduct](https://bioconductor.github.io/bioc_coc_multilingual/).
Everyone who takes part in the project, in issues, pull requests, reviews and
any other discussion, is expected to follow it.

To report behaviour that breaks it, write to the maintainer, Priyansh
Srivastava, at spriyansh29@gmail.com; reports are handled in confidence. You
can also report it to the Bioconductor Code of Conduct Committee at
code-of-conduct@bioconductor.org.
